# 🚀 Tech AI Commerce

> Automatización inteligente del proceso de onboarding de clientes mediante n8n.

## 📌 Descripción

Tech AI Commerce es una solución de automatización diseñada para optimizar el proceso de incorporación de nuevos clientes una vez se confirma el pago.

El flujo automatiza la recepción de la información del cliente, identifica el plan contratado (Starter, Growth o Premium), registra la información en Airtable, crea tareas y subtareas en ClickUp y notifica automáticamente al equipo de trabajo mediante Slack, reduciendo significativamente el trabajo manual y los tiempos de respuesta.

## ✨ Funcionalidades principales

- Recepción automática de nuevos clientes.
- Clasificación automática según el plan contratado.
- Registro automático de la información en Airtable.
- Creación de tareas y subtareas en ClickUp.
- Notificaciones automáticas al equipo mediante Slack.
- Transformación y validación de datos con JavaScript.
- Arquitectura basada en Webhooks para la automatización del proceso.
